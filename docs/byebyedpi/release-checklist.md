# Ворота выпуска TG-WS Proxy с ByeByeDPI

**Статус: выпуск заблокирован.** Выполнять проверки на одном зафиксированном коммите кандидата. Не сохранять секрет TG, ключи подписи, файлы пользовательского импорта или токены в протоколе.

| Проверка | Текущее состояние | Требуемое доказательство |
|---|---|---|
| Исходники и лицензии обоих движков | Локально проверялись: офлайн-проверка снимков; дерево ByeByeDPI и рекурсивные зависимости закреплены | Повторить на SHA кандидата, проверить лицензии и список изменений |
| Android/Linux CI, две ABI | Локальные сборки Windows: ARM64 unsigned release и x86_64 debug, обе библиотеки DPI и 16 КБ проверены | Зелёный доверенный CI на SHA кандидата, включая API 24 и актуальный Android |
| Package ID, разрешения и старые TG-действия | Локальный аудит ARM64 unsigned release пройден | Повторить аудит итогового подписанного APK; сверить отпечаток с прежним публичным релизом |
| Обновление на устройстве | **Не проверено** | Установить прежний подписанный APK; записать версию, порт TG и факт наличия секрета (не его значение); обновить подписанным кандидатом с большим versionCode; проверить сохранение секрета локальным сравнением и отсутствие автозапуска нового VPN |
| Чистая установка | Частично: эмулятор API 35 (x86_64), minified release с временным ключом, холодный запуск и стабильный PID, VPN не стартовал сам | Повторить на API 24, ARM64, Android TV/BOX; проверить доступность настроек пультом и при крупном шрифте |
| Независимость движков | JVM-тесты статусов пройдены; устройство **не проверено** | TG, SOCKS5, VPN отдельно; затем TG+SOCKS5 и TG+VPN; остановить в обоих порядках, проверить реальный TG и контрольное HTTP-соединение; повторить при занятом порте |
| Сторонний VPN, отказ и отзыв | JVM-тесты решения пройдены; устройство **не проверено** | Активный сторонний VPN, отказ/отмена, изменение наблюдаемой сети после подтверждения, отзыв, always-on/lockdown, смена сети, смерть процесса. Проверить маршруты и уведомления, не только цвет кнопки |
| Паритет пользовательских инструментов | **Не закрыт** | Сопоставить с [матрицей](parity.md); приложить результаты оригинала и кандидата без установленного оригинала на тестовом устройстве. Неперенесённые действия блокируют выпуск |
| PR обновления и откат | Локальная логика стабильных тегов и синтаксис проверены; GitHub **не проверен** | На разрешённой тестовой ветке доказать один draft PR и запуск проверок без подписи или публикации. Затем откатить снимок и подтвердить сборку и новый versionCode |
| Документация, визуальные материалы и права | **Не закрыто** | Проверить быстрые старты RU/EN, обновить скриншоты, получить согласование и подтвердить права перед заменой значка |

Для каждого прогона записать SHA, дату, API/ABI и тип устройства, шаги, результаты и ссылку на обезличенный лог. Сборка, статический аудит и проверка запуска не заменяют проверку маршрутизации или подписанной миграции. Не публиковать кандидата, пока все ворота не закрыты и владелец не разрешил публикацию.
