# Правки при сборке README

Что изменилось в `docs/assets/design/copy/README.ru.md` / `README.en.md` при переносе в корень репозитория. Содержательные разделы не переписывались — только перечисленное ниже.

## Неподтверждённые утверждения

1. **«Свой воркер не делит квоту с другими пользователями» — удалено в двух местах (RU и EN).**
   - «Возможности», пункт про Cloudflare: вместо «воркеры пробуются первыми и не делят квоту» осталось проверяемое «ядро пробует их первыми, до CF-прокси и прямого подключения, даже при выключенном CloudFlare CDN».
   - «Свой Cloudflare»: последнее предложение про квоту удалено целиком.
   - Причина: в коде виден только порядок попыток (`upstream/flowseal/proxy/bridge.py:144–157`), механика квот Cloudflare не проверяется; см. `claims-check.md`, п. 2 раздела «Что не удалось подтвердить кодом».

2. **Таблица режимов, строка MTProto (RU и EN): «не меняет твой IP для Telegram» — заменено на «не перехватывает трафик других приложений и не занимает VPN-слот».**
   - Причина: утверждение про IP не проверяется кодом и не следует из архитектуры; запрет на VPN-слот и отсутствие перехвата подтверждены (`DpiVpnRouting.kt:33`, `proxy/bridge.py`).

3. **«Техническая документация», финальный абзац (RU и EN): «В README ниже остались только…» — переписано.**
   - Было заявление про «ниже» и про порядок разделов, которого в файле нет, плюс слово «остались» намекало, что части текста больше нет.
   - Стало: «Всё, что нужно при установке и первом запуске, есть в этом файле: …» со ссылками на реально существующие разделы (Доступы, Свой Cloudflare, Управление без интерфейса, Диагностика, Проверка APK, Сборка).
