# TG-WS Proxy by derigava_ — проект первого объединённого релиза

**Согласовано 20 ноября 2026 года.** Цель: один подписанный Android APK вместо двух приложений. Telegram по-прежнему подключается к локальному MTProto; справа запускается полноценный ByeByeDPI. Это не переименование чужого движка: авторство обоих upstream сохраняется.

## Решения пользователя

- Название продукта TG-WS Proxy, подпись `by derigava_`. Не TG VS, не название автора вместо названия продукта.
- На главном две независимые кнопки. Макет подтверждает компоновку и взаимодействие, не форму кнопок. Оригинальный `CursorSwitch` из `ConnectionTab.kt` — визуальный эталон для пары: одинаковая геометрия, анимация, типографика и правила индикации. TG-WS слева, ByeByeDPI справа; статус, подпись, целевое действие и доступность — отдельно у каждой кнопки. Нынешний текст справа от TG-кнопки переразместить под соответствующим модулем, не потеряв адрес и «Применить в Telegram». На узком экране переносить подписи, не менять порядок кнопок.
- В «Настройках» сверху TG-WS | ByeByeDPI; общие доступы и обновления в одном месте. Все пользовательские экраны ByeByeDPI, включая вспомогательные инструменты, оформлены в стиле существующего TG-WS уже в первом релизе. Логи разделяются по источнику.
- По умолчанию ByeByeDPI обслуживает весь телефон в текущем профиле через Android VPN. Второй режим — локальный SOCKS5. Оба без root. TG-WS не требует VPN и может работать вместе с каждым из режимов.

## Подходы

Выбран: своё представление всех возможностей на Compose с повторным использованием существующих сервисов/движков upstream через адаптер. Дороже в проверке паритета, зато пользователю не приходится осваивать два интерфейса. Альтернатива — встроить и постепенно перекрасить готовые экраны; дешевле первоначально, но не отвечает решению пользователя. Управление внешним APK не заменяет отдельное приложение и исключено.

## Что считать полноценной заменой

База сравнения — [официальный релиз v.1.8.2](https://github.com/romanvht/ByeByeDPI/releases/tag/v.1.8.2); проверенный Git SHA тега `96a3c1ff555043d915af814aa4f0e9a572c89aba`. В lock закрепить также рекурсивные зависимости. Первый артефакт реализации — таблица «экран/действие оригинала → эквивалент TG-WS → сценарий приёмки»: построить по реальному приложению, ресурсам, manifest и исходникам, а не только README. Оба режима, фильтры приложений, управление стратегиями, проверки/подбор, настройка параметров, диагностика, перенос поддерживаемых форматов и внешние точки запуска проверяются там, где доступны в эталоне. README эталона отдельно подтверждает автозапуск выбранного режима после загрузки, сохранённые списки параметров командной строки, раздельное туннелирование, импорт/экспорт и совместимость с Android TV/BOX: включить навигацию пультом и проверку фокуса в матрицу. Нативную сборку hev на рабочих станциях Windows планировать через WSL, в CI — через Linux. Ничего не исключать молча: отсутствие эквивалента блокирует релиз. Не обещаем чтение приватных данных чужого APK или поддержку его package ID в сторонних автоматизациях. Обновления upstream после базовой версии проходят отдельное сравнение.

## Контракты и ограничения (предложения для реализации)

- Сохранить applicationId `io.github.derigava.tgwsproxy`, подпись и монотонный versionCode, настройки/секрет TG, существующие ярлыки, плитку, действия автоматизации. Старые действия продолжают управлять исключительно TG. Новые настройки, порты, id уведомлений и команды изолированы. Ошибка старта одного сервиса не останавливает другой. Не связывать «работает» с одним только фактом нажатия. Восстановление экрана берёт состояние из сервиса. Никакого автозапуска нового VPN при обновлении.
- Не отзывать сторонний VPN без явного выбора. Перед захватом слота показать последствия, при активном или неопределённом состоянии предложить SOCKS5, переключение с подтверждением или отмену. Отказ в системном согласии, отзыв VPN или always-on/lockdown не должны приводить к ложному статусу или циклу перезапуска. Прокси сам трафик телефона не перенаправляет; совместная работа с другим VPN зависит от маршрутизации клиента. Не обещать два VPN одновременно или работу SOCKS5 под любой системной политикой. Предложение: исходящие соединения TG-WS идут своим маршрутом, не через наш ByeByeDPI. Фильтр приложений не приписывает соединения локального MTProto-посредника клиенту Telegram; явно описать это и исключить зацикливание. Внешним приложениям не давать безусловного права менять стратегию или включать сервис: подтверждение как у существующих действий TG, без молчаливого захвата VPN.
- Разделить адаптеры Android, нативные сборки и UI; не переписывать движок для смены внешнего вида. Проверить Android 7+/ARM64 и актуальную версию ОС, emulator ABI для CI; техническая несовместимость не повод незаметно урезать текущую поддержку. Ошибка биндинга порта объясняется пользователю. Настройки и логи не раскрывают секреты в отчётах. Сохранить блокировки на установку APK из приложения.
- Кандидат на иконку из предоставленного архива — `11-route-e`, не утверждённый финальный знак. Проверить адаптивные маски, монохром и читаемость на 24 px; соблюсти условия брендовых материалов отдельно от GPL. Название обновить в launcher, заголовках, уведомлениях, RU/EN README, баннерах и скриншотах. Не переименовывать пакет, репозиторий и публичные ссылки из косметических соображений.

## Actions и поставка

Существующая суточная проверка Flowseal только выводит доступный тег. Для ByeByeDPI — отдельный lock с репозиторием, тегом, SHA, зависимостями и контрольными суммами. Суточный поиск стабильного релиза идемпотентно открывает/обновляет PR на новый снимок; нет новой версии — нет PR. Не менять политику Flowseal. На PR проверяются содержимое снимка, лицензии, сборки ABI, матрица паритета и регрессии TG. Секретов подписи в PR нет. Не собирать релиз с плавающей ветки, не публиковать непроверенное автоматически; после ревью — штатный подписанный выпуск. На устройстве обновляется только всё приложение. Предусмотреть возврат к предыдущему lock в новой версии APK.

## Документация и выпуск

RU/EN README: две инструкции первого запуска, оба режима и их пределы, разрешения, что делать при другом VPN, совместная работа с TG, импорт настроек при наличии совместимого файла, версии и ссылки на исходники/лицензии компонентов, получение подписанного APK. Убрать общие обещания «VPN не нужен»; не обещать шифрование или смену IP. Привязать соответствующие исходники нативных компонентов и патчей к релизному тегу.

Ворота выпуска: чистая установка и обновление поверх текущего подписанного приложения без потери настроек; паритет с базой на поддерживаемых устройствах без установленного оригинала; TG отдельно, ByeByeDPI в каждом режиме отдельно и одновременно с TG; остановка в обоих порядках, отзыв/отмена VPN, сторонний VPN, смена сети, восстановление процесса, потеря разрешений, занятый порт; автоматическое обнаружение нового upstream и отсутствие изменений при повторном запуске; проверка артефактов и обновлённых инструкций. Подбор стратегии не является гарантией доступа к любому сайту у любого провайдера.
